## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Main product - compact.
2. Assign the compact product template to a product, then arrange the title, price, variants, quantity, buy buttons, and description blocks.
3. Native option swatches appear when option values have color or image swatch data. The full media disclosure includes every product image and rich media item.
4. Select Add block inside this section. Use the supported block types listed below, then drag them into the desired reading order.
5. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
6. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.
