# Product block section

[All documentation](../README.md) · [Support](../SUPPORT.md)

Products.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Product block section.
2. Add a product layout row, add a column inside it, then insert product or content blocks in the column.
3. Use the product form block to group purchase controls. Keep one authoritative variant and quantity control for each form, and test the cart after changing the structure.
4. Select Add block inside this section. Use the supported block types listed below, then drag them into the desired reading order.
5. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
6. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Template availability: `{"enabled_on": {"templates": ["product"]}, "disabled_on": null}`.
