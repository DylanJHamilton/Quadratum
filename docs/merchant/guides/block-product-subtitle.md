# Product subtitle

[All documentation](../README.md) · [Support](../SUPPORT.md)

Products.

## Add and configure

1. Open a compatible section or parent block in the theme editor, select Add block, and choose Product subtitle. The parent controls its available space and overall layout.
2. Configure the block’s content first, then its presentation. Drag the block in its parent to change its position.
3. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Compatible sections: Product block section.

## Subtitle content

### Subtitle source

Choose one of the supported options below for subtitle source. Only the selected option applies; other settings can further customize its appearance.

Default: `custom`.

Options: Custom text, Product metafield, Product tagline metafield.

<details><summary>Reference for connected builders</summary>

Setting: `subtitle_source`. Type: `select`.

`custom`, `metafield`, `tagline`

</details>

### Custom text

Use the rich text editor for paragraphs, lists, emphasis, and links. Use descriptive link text and headings in a logical order.

Default: `<p>A short product tagline or marketing subtitle that helps shoppers understand the product faster.</p>`.

<details><summary>Reference for connected builders</summary>

Setting: `custom_text`. Type: `richtext`.

</details>

### Metafield namespace

Advanced: enter the namespace of an existing Shopify metafield definition, such as custom. It must match the definition exactly. Pair it with the corresponding key; this setting does not create a definition.

Default: `custom`.

<details><summary>Reference for connected builders</summary>

Setting: `metafield_namespace`. Type: `text`.

</details>

### Metafield key

Advanced: enter the existing metafield key or content field key described below. Match the spelling exactly and use the data type expected by this section. Use manual content first if no matching definition exists.

Default: `subtitle`.

<details><summary>Reference for connected builders</summary>

Setting: `metafield_key`. Type: `text`.

</details>

### Wrap plain text in a paragraph

Turn on “Wrap plain text in a paragraph” to apply that behavior. Turn it off to remove that behavior. Other settings can affect whether the result is visible; check the section preview after changing it.

Rich text keeps its own paragraph and list markup.

Default: `True`.

<details><summary>Reference for connected builders</summary>

Setting: `render_as_paragraph`. Type: `checkbox`.

</details>
