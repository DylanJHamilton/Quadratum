Build notes

  • 18 new editable JSON templates, reusable directory and theme-local navigation installed in QA.
  • About, Contact, search and wishlist retained and linked. Cart and404 configured. Popup opens on request.
  • Two initial blog uploads rejected rich-text formatting; corrected and accepted in store-blog-upload.json.
  • Classic mobile gallery overflow fixed: automatic grid track minimum expanded to eight thumbnails; explicit minmax(0,1fr) and bounded wrapper restore document363/client363, viewer315.

Remaining release work and limits

  • Ten-brand gallery links to original demo themes; those themes were not replaced with ULTIMA.
  • Other preset configurations are versioned in listings; they were not all installed and visually accepted in this pass.
  • New page views reuse existing Shopify resources. Shared catalog, page assignments and menus unchanged.
  • No purchase, checkout or form submission performed. Performance, compliance and warning review remain release gates.
  • Previous automated suites were not rerun during this build. Settings validation, upload acceptance and browser observations are recorded.
