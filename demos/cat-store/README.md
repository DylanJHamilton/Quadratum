# Morrow Cat Co. / Quadratum sample store

**Branch:** `demo/sample-cat-store-20261007`  
**Shopify implementation:** Quadratum native homepage sections plus three Morrow Cat Co. niche sections.  
**Status:** Unpublished Shopify theme demo; concept catalog only.

## Homepage and theme test

The homepage uses Quadratum's native Hero Banner, Column Builder, CTA Banner, and Basic Text Content sections for the main storefront structure. The Quadratum header, footer, and theme settings remain in use. Three Morrow-specific sections provide cat collection cards, the fictional concept catalog, and a playful day picker.

The catalog contains 24 fictional concepts with generated art and illustrative prices. It is not connected to Shopify product records, inventory, cart, or checkout. The disclosure at the bottom explains the demo status.

## Preview

Preview through Shopify's unpublished theme workflow. This repository change does not create product records, publish a theme, or activate checkout. Replace concept artwork and copy with approved commercial assets and verified supplier information before any live use.
