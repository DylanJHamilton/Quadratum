# Main search

[All documentation](../README.md) · [Support](../SUPPORT.md)

Store essentials.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Main search.
2. Search results come from Shopify. Choose searchable content types in Theme Settings > Search settings.
3. Product filters appear when Shopify supplies configured filters. Configure them with Shopify Search & Discovery. Applying product filters narrows the request to products; clearing filters restores the configured result types.
4. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
5. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.
