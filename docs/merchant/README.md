# Quadratum documentation

Learn how to configure your theme, choose templates, and use every section, block, and Theme Settings group included in the merchant package.

[Contact support](SUPPORT.md)

## Getting started

<h2>From a blank store to your first collection.</h2>
        <ol class="q-docs__steps">
          <li><strong>Work on a copy.</strong> In Online Store → Themes, duplicate your theme and open Customize. Save changes to that unpublished copy while you build.</li>
          <li><strong>Prepare your catalog.</strong> Add products, prices, inventory, variants, media, and collections in Shopify. Theme settings display that information; they do not create products, shipping rates, taxes, or discounts.</li>
          <li><strong>Choose a preset.</strong> The five install presets are Quadratum, Morrow, Northstar, Kinvar, and Vantier. Pick the nearest visual starting point, then add your own content. Preview changes before saving a new preset.</li>
          <li><strong>Set the shared design.</strong> Open Theme Settings. Start with Branding, colors, typography, buttons, and layout. Select an actual Shopify font; check bold and italic text as well as ordinary body text.</li>
          <li><strong>Build navigation.</strong> Create menus in Content → Menus. Use Main menu and Footer menu in the header and footer. Link to actual products, collections, pages, and blog posts in your store.</li>
          <li><strong>Compose the home page.</strong> Choose a clear opening section, a featured collection or product group, a useful product story, and a final action. Add blocks inside sections, reorder them, and check each section’s spacing against its neighbors.</li>
          <li><strong>Assign templates.</strong> Select a product, collection, page, blog, or article in Shopify and use its Theme template field. Templates belong to the theme; a preview URL alone does not assign a template to content.</li>
          <li><strong>Review the journey.</strong> Check mobile and desktop navigation, filters, product options, cart, search, contact forms, and empty states. Review your payment, shipping, policy, and domain settings in Shopify before publishing.</li>
        </ol>
        <details open><summary>Sections, blocks, and Theme Settings</summary><p><strong>Sections</strong> are the main page areas. <strong>Blocks</strong> are smaller pieces inside a section or parent block. <strong>Theme Settings</strong> provide shared defaults across the store. A local section or block override can take priority over a shared default.</p><p>Start with content, then layout, then appearance. Use one strong heading per area, consistent horizontal edges, and deliberate space between sections. Avoid stacking several large centered introductions.</p></details>
        <details><summary>Product and collection presentations</summary><p>Modern, Classic, Simple, and Compact product templates use the same Shopify product data with different arrangements. Keep title, price, variants, quantity, buy buttons, and description visible. Use app blocks or Custom Liquid for supported additions.</p><p>Collection templates can arrange products as grids or lists, with different sidebar and editorial treatments. Configure filters in Shopify Search &amp; Discovery; the theme displays the filters Shopify returns. Use real products with multiple options to review the buying experience.</p></details>
        <details><summary>Images, video, and focal points</summary><p>Upload clear source images in Shopify Files. Set alt text and the focal point there or through the image picker. Select mobile imagery where a section offers it. Use a deliberate crop and compare portrait, square, and wide images before choosing a ratio.</p><p>Product rich media comes from the product’s Media area. Video should have a useful poster and playback controls. Reduced-motion preferences are respected by supported theme animation features.</p></details>
        <details><summary>Typography, color, spacing, and overrides</summary><p>Set heading and body fonts in Theme Settings → Branding. Shared spacing and container values establish the page rhythm. Section padding controls space around a section; gaps control space between its children.</p><p>Choose foreground and background colors together. Check body text, secondary text, buttons, hover states, and keyboard focus. When a global change appears to have no effect, inspect the section’s own color or typography override.</p></details>
        <details><summary>Metafields and reusable product information</summary><p>Start with manual content. For reusable data, create a suitable definition in Shopify Settings → Custom data, fill it on the product, and connect it using the dynamic-source control or the section’s namespace and key fields.</p><p>Advanced reference modes read a product metafield containing a metaobject reference or list. The theme does not install custom definitions. A missing definition produces no reference content; use the manual alternative until your data exists.</p></details>
        <details><summary>Cart, promotions, and saved products</summary><p>Choose cart behavior in Theme Settings → Commerce defaults. Test quantity changes, unavailable products, selling plans, and line item information. Free-shipping progress and reward labels must correspond to real rules configured in Shopify.</p><p>Saved products use this browser’s local storage. They are not a customer-account service and do not sync between devices. Clearing browser data removes the saved list.</p></details>
        <details><summary>Popup, search, and customer accounts</summary><p>Configure newsletter popup content and frequency in Theme Settings, and confirm mobile behavior before enabling it. Search can display products, articles, pages, and predictive collection suggestions. Customer account behavior is provided by Shopify when accounts are enabled.</p><p>Preview newsletter and contact messages using your actual store configuration. A successful visual preview does not prove email delivery.</p></details>
        <details><summary>Build with ChatGPT or Claude</summary><p>Give your assistant your business, catalog, brand direction, and required pages. Ask it to read only the relevant section and block schemas, use existing controls, and work in an unpublished copy. Theme-file access must be explicitly supported by your connector; catalog access alone does not provide it.</p><p>Use the <a href="#working-with-connected-builders">builder reference</a> for exact file and setting names. Review generated content, links, and purchases yourself before publishing. No token-saving benchmark or platform endorsement is claimed.</p></details>
        
        <details><summary>Update safely and ask for help</summary><p>Duplicate the theme before updating or editing code. Record the theme version, template, section, and steps that reproduce an issue. Theme support can address setup questions and reproducible theme bugs. Custom code, third-party apps, and store operations may need separate assistance.</p><p>Use the <a href="SUPPORT.md">support form</a> and include the affected page and screenshots. Do not send passwords, access tokens, payment data, or customer details.</p></details>
