# Appointment request

[All documentation](../README.md) · [Support](../SUPPORT.md)

Content and merchandising.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Appointment request.
2. Set the heading and explanatory text. The native contact form can collect a preferred date.
3. This sends an appointment request; it does not reserve a time or manage availability. Confirm appointments separately.
4. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
5. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Uses Shopify’s native contact form. This sends an inquiry; it does not reserve a time, create a booking, or connect to a CRM.
