# Product gallery

[All documentation](../README.md) · [Support](../SUPPORT.md)

Products.

## Add and configure

1. Open a compatible section or parent block in the theme editor, select Add block, and choose Product gallery. The parent controls its available space and overall layout.
2. Configure the block’s content first, then its presentation. Drag the block in its parent to change its position.
3. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Compatible sections: Product block section.

## Gallery mode

### Gallery mode

Choose one of the supported options below for gallery mode. Only the selected option applies; other settings can further customize its appearance.

Default: `slider`.

Options: Slider, Gallery, Masonry, Horizontal thumbnails.

### Main media ratio

Drag the control to adjust main media ratio. Use only the range and increments shown below. Preview at mobile and desktop widths after changing spacing or dimensions.

Width divided by height as a percentage; 125 produces a 1.25:1 frame.

Default: `125`.

Range: 60 to 180 %; step 5.

Setting: `main_media_ratio`. Type: `range`.

</details>
