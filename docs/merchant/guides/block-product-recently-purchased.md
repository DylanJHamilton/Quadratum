# Recently purchased

[All documentation](../README.md) · [Support](../SUPPORT.md)

Products.

## Add and configure

1. Open a compatible section or parent block in the theme editor, select Add block, and choose Recently purchased. The parent controls its available space and overall layout.
2. Configure the block’s content first, then its presentation. Drag the block in its parent to change its position.
3. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Compatible sections: Product block section.

## Message

Static merchant text only. No order, viewer, location, cart or popularity feed is connected. Add only messages you can substantiate; optional random selection uses your configured messages.
