# Branding

[All documentation](../README.md) · [Support](../SUPPORT.md)

Theme Settings.

## Add and configure

1. Open Online Store > Themes > Customize, then select Theme Settings and Branding.
2. Select desktop and mobile logos, then a favicon and social share image. Set heading and body fonts before adjusting sizes and line heights.
3. Set base background and text as a pair. Review the separate button, badge, muted text, and dark-mode pairs. Section overrides can keep their own colors.
4. Set shared defaults here. A section with its own override may retain that override; select the section to adjust it.
5. Preview a home, product, collection, and cart page before saving shared changes.
