# Collection cards

[All documentation](../README.md) · [Support](../SUPPORT.md)

Collections.

## Add and configure

1. Open a compatible section or parent block in the theme editor, select Add block, and choose Collection cards. The parent controls its available space and overall layout.
2. Configure the block’s content first, then its presentation. Drag the block in its parent to change its position.
3. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Compatible sections: Block section, Product block section.

## Collections

### Collection source

Choose one of the supported options below for collection source. Only the selected option applies; other settings can further customize its appearance.

Default: `manual`.

Options: Manual collections, Featured collection.

</details>
