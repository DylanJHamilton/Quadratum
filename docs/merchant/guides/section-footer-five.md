## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Department footer.
2. Select Add block inside this section. Use the supported block types listed below, then drag them into the desired reading order.
3. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
4. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Template availability: `{"enabled_on": {"groups": ["footer"]}, "disabled_on": null}`.

### Use section colors and card radius for blocks

Turn on “Use section colors and card radius for blocks” to apply that behavior. Turn it off to remove that behavior. Other settings can affect whether the result is visible; check the section preview after changing it.

Enable to apply the section controls throughout the footer. Disable to use each block’s saved overrides.

Default: `False`.

<details><summary>Reference for connected builders</summary>

Setting: `inherit_block_styles`. Type: `checkbox`.

</details>
