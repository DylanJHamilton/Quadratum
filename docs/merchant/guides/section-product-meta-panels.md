# Product meta panels

[All documentation](../README.md) · [Support](../SUPPORT.md)

Products.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Product meta panels.
2. Add one panel block per subject, then choose tabs, cards, or a table. Use Manual content for a quick start.
3. For a referenced entry, configure its product metafield namespace and key, then list the entry field keys to display in the Field key control.
4. Select Add block inside this section. Use the supported block types listed below, then drag them into the desired reading order.
5. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
6. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

Up to 12 blocks can be added.
