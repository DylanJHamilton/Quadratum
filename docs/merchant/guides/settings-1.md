# Theme settings

[All documentation](../README.md) · [Support](../SUPPORT.md)

Theme Settings.

## Add and configure

1. Open Online Store > Themes > Customize, then select Theme Settings and Theme settings.
2. The tagline and announcement here are fallbacks. If a header or announcement section supplies its own text, edit that section too. Any shipping promise must match an actual Shopify shipping rule.
3. Set shared defaults here. A section with its own override may retain that override; select the section to adjust it.
4. Preview a home, product, collection, and cart page before saving shared changes.

## Basic theme settings

### Site tagline

Enter the site tagline. Replace sample wording with your own content; leave optional fields empty when you do not need them.

Default: `Premium products, built beautifully.`.

<details><summary>Reference for connected builders</summary>

Setting: `site_tagline`. Type: `text`.

</details>

### Announcement bar text (fallback)

Enter the announcement bar text (fallback). Replace sample wording with your own content; leave optional fields empty when you do not need them.

Default: `Free shipping on orders over $75!`.

<details><summary>Reference for connected builders</summary>

Setting: `announcement_text`. Type: `text`.

</details>
