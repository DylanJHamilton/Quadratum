VANTIER refinement log — 15 October 2026
Scope: unpublished theme 146590105684; demo/vantier-fashion-20261015.

QTM-VAN-01 — Header One navigation collision — theme layout bug
Nine top-level links at about 1060px collided with the search action. The original breakpoint stayed at 989px regardless of menu length. Menus with more than seven links now use a 1199px breakpoint; the JavaScript resize handler reads the same breakpoint. This is a guard for the demonstrated menu, not a complete solution for arbitrarily long translated labels.

QTM-VAN-02 — Collection Classic sort squeezing — theme layout bug
The select requested 100% width inside a flex row, while label and submit button could shrink and wrap. Select now flexes within a bounded desktop group; label and button retain their intrinsic widths and stay on one line. Mobile still uses the available row width.

QTM-VAN-03 — Product Spotlight empty despite selected products — theme data handling bug
The section applied slice to Shopify's product-list drop and then indexed the result for its hero product. The resulting hero was blank. Retain the product list, select the hero by iteration, and apply limits to rendering loops. Browser inspection after this code change showed products rendering before the manual configuration was changed. Curated manual products are retained in the final configuration.

QTM-VAN-04 — Seven edits inconsistent image heights — section capability gap/configuration
Media carousel renders natural image height and has no image ratio control. VANTIER's section-level CSS supplies consistent 4:5 frames and equal-height cards. No global forced crop was added. A reusable ratio setting remains a future theme enhancement.

QTM-VAN-05 — Finishing chapter unreadable — configuration mistake
Light colors were configured with use_alt_background=false. Enable the native background switch and size the chapter heading for the intended editorial treatment.

QTM-VAN-06 — Hero garbled separators — content encoding mistake
Removed the extra encoded character before middle-dot separators.
