NS-04 | Quadratum defect

main-product-classic.liquid excerpt

Severity: medium

Reproduction: Use adjacent paragraphs in a product description. The excerpt concatenates the last word of one paragraph with the first of the next.

Cause: strip_html removes paragraph boundaries without inserting whitespace.

Resolution: Normalize paragraph, list-item and line-break boundaries before stripping HTML.

Status: fixed on Northstar branch

NS-05 | Quadratum defect

main-collection-classic.liquid filter fieldsets

Severity: high

Reproduction: Set dark surface and light text colors. Filter fieldsets remain translucent white, weakening contrast.

Cause: Hard-coded rgba(255,255,255,0.55) background ignores configured surface color.

Resolution: Use the section surface token.

Status: fixed on Northstar branch
