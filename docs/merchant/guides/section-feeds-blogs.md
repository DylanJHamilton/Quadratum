# Feeds - blog list / grid

[All documentation](../README.md) · [Support](../SUPPORT.md)

Journal.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Feeds - blog list / grid.
2. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
3. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

## Content

### Blog source

Choose an existing blog. Create and manage its articles in Shopify’s blog post editor.

Uses the current blog on blog/article pages when unselected. Choose a source on other pages.

<details><summary>Reference for connected builders</summary>

Setting: `blog`. Type: `blog`.

</details>

### Optional tag filter

Enter the optional tag filter. Replace sample wording with your own content; leave optional fields empty when you do not need them.

Shows matching articles from the available preview (up to 50 articles), with a link to the complete tagged archive. Leave blank for native pagination.

<details><summary>Reference for connected builders</summary>

Setting: `filter_tag`. Type: `text`.

</details>

### Posts per page
