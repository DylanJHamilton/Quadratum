# Collection list

[All documentation](../README.md) · [Support](../SUPPORT.md)

Collections.

## Add and configure

1. Open Online Store > Themes > Customize for an unpublished copy. Choose the page template, select Add section, and choose Collection list.
2. This section lists collections. Select the desired collections or use the store collection list.
3. Set each collection’s image in Shopify. The first product image is used when a collection image is absent.
4. Select Add block inside this section. Use the supported block types listed below, then drag them into the desired reading order.
5. Connect your own content and media before adjusting layout, typography, color, and spacing. Section overrides take priority where the section offers them.
6. Preview desktop and mobile, test any links or controls, and save. Publish only after reviewing the complete customer journey.

### Use as collections page heading

Turn on “Use as collections page heading” to apply that behavior. Turn it off to remove that behavior. Other settings can affect whether the result is visible; check the section preview after changing it.

Default: `False`.

<details><summary>Reference for connected builders</summary>

Setting: `page_heading`. Type: `checkbox`.

</details>
