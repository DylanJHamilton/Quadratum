# Builder admission

Both section → row → column gateways are retained. Columns explicitly list their content types; product columns cannot recursively introduce either layout system. App blocks are allowed at the existing section and column positions.

Page columns admit 61 page-safe blocks. Product columns admit 98 content blocks. Product-prefixed blocks and content-product-recommendations require product context. The latter builds its recommendation URL from the current product ID, so it is product-only despite its content prefix. Other collection/product merchandising content blocks expose merchant-selected sources and remain page-safe.
